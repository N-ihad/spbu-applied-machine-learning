# ДЗ № 2. Агрегация асессорских оценок на RTE-1

В эксперименте Snow et al. асессоры Amazon Mechanical Turk читали два предложения и решали, следует ли второе из первого. Для каждой пары есть экспертный ответ из корпуса RTE-1. [Статья о сборе данных, раздел 4.3](https://aclanthology.org/D08-1027.pdf) · [Голоса и экспертные ответы](https://github.com/dirkhovy/MACE/tree/10f231ee2d43d6e38c777cbbed299f9ecd1c2d07/data/test)

## Данные

В корпусе 800 пар предложений, по 400 каждого класса. Каждую пару оценивали десять человек. Всего получено 8 000 голосов от 164 асессоров.

| Как разделились голоса | 10 против 0 | 9 против 1 | 8 против 2 | 7 против 3 | 6 против 4 | 5 против 5 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Число пар предложений | 78 | 130 | 198 | 164 | 165 | 65 |

У заданий одинаковое число ответов, но нагрузка на людей различается. Из 164 асессоров 124 оценили всего по 20 пар, один оценил все 800. Пятеро самых активных дали 40,25% голосов.

Два случайно выбранных асессора, оценивших одну пару, совпадают в ответе в 62,87% случаев. На класс 1 приходится 57,26% голосов. С поправкой на совпадения, ожидаемые при таких частотах классов, каппа Флейса равна 0,241. Полное согласие встретилось на 78 парах, ровно поровну голоса разделились на 65.

## Методы

Для калибровки взяты 160 пар, по 80 каждого класса. Остальные 640 оставлены для проверки. Разбиение по парам зафиксировано с seed 42. Все десять голосов за одну пару попадают в одну выборку.

- **Majority Vote.** Каждый голос имеет вес 1. При равенстве выбирается класс 0. Это же правило действует для остальных методов.
- **Weighted Majority Vote.** По экспертным ответам на калибровочных парах оценивается точность каждого асессора. К его ответам добавляются пять условных ответов со средней по группе точностью. Если сглаженная точность равна `p`, вес голоса равен `max(0, ln(p / (1 − p)))`.
- **Dawid–Skene.** По одним только голосам на калибровочных парах EM-алгоритм оценивает доли классов и матрицу ошибок каждого асессора. Начальное приближение задают доли голосов, при оценке вероятностей к счётчикам добавляется единица. На тесте используются зафиксированные параметры. [Dawid и Skene, 1979](https://doi.org/10.2307/2346806)

## Результаты

| Метод | Верных ответов из 640 | Accuracy | Macro-F1 |
| --- | ---: | ---: | ---: |
| Majority Vote | 589 | 92,03% | 0,92030 |
| Weighted Majority Vote | 597 | 93,28% | 0,93280 |
| Dawid–Skene | 589 | 92,03% | 0,92026 |

На тесте отдельный голос совпадал с экспертным ответом в 72,56% случаев. Взвешенное голосование исправило 17 ошибок большинства и добавило 9 новых. Выигрыш составил 8 пар, или 1,25 п. п. Парный 95%-й бутстрэп-интервал для разницы accuracy включает ноль (от −0,31 до +2,81 п. п., 5 000 перевыборок пар с сохранением долей классов).

Dawid–Skene и обычное большинство дали одинаковое число верных ответов. При этом Dawid–Skene реже ошибочно выбирал класс 1 (17 раз против 29) и чаще пропускал его (34 раза против 22).

Большинство чаще ошибалось на спорных парах. При счёте 5 против 5 или 6 против 4 оно ошиблось на 33 парах из 182 (18,13%). При восьми и более совпавших голосах ошибок было 7 из 321 (2,18%). В 40 из 50 тестовых ничьих эксперт выбрал класс 0. При случайном разрешении ничьих ожидаемая accuracy большинства составила бы 89,69%.

## Запуск

Команды выполняются из корня репозитория на macOS или Linux с Python 3.11–3.14.

```bash
git switch hw2_crowd_aggregation
cd hw2
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest -v
python experiment.py --output results.json
```

При первом запуске скрипт скачивает два файла RTE-1 в `data/` и проверяет SHA-256. Повторный запуск использует локальные копии. Полные матрицы ошибок, интервалы и статистика голосов сохранены в [results.json](results.json).
