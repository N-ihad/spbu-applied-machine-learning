# ДЗ № 1. Классификация изображений STL-10

Как меняется точность ResNet-18 и MobileNetV3-Small, если четверть каждого батча дообучения заменить изображениями с псевдометками? Для каждой архитектуры сравниваются два продолжения одного и того же обучения. В обеих сериях используются поэтапное усиление аугментаций и разморозка блоков с адаптивной скоростью обучения.

## Данные

В STL-10 десять классов цветных изображений размером 96 × 96. Из официального `train` в обучение попали 4 000 изображений, а в валидацию - 1 000. В каждом классе ровно 400 и 100 изображений соответственно. Для обеих сетей зафиксировано одно разбиение с seed 42. Все 100 000 изображений `unlabeled` участвуют в отборе псевдометок. Официальный `test` содержит 8 000 изображений, по 800 на класс. [Описание STL-10 и исходный протокол авторов](https://cs.stanford.edu/~acoates/stl10/)

Авторы собрали STL-10 из изображений ImageNet. Начальные веса обеих сетей получены на ImageNet-1K, поэтому возможны пересечения с данными предобучения. Результаты ниже характеризуют перенос весов на выбранном разбиении. Стандартный протокол STL-10 предусматривает отдельные запуски на предопределённых подвыборках. [Веса ResNet-18](https://docs.pytorch.org/vision/stable/models/generated/torchvision.models.resnet18.html) · [Веса MobileNetV3-Small](https://docs.pytorch.org/vision/stable/models/generated/torchvision.models.mobilenet_v3_small.html)

Ожидаемая точность случайного ответа на сбалансированном тесте равна 10%. Для ориентира по сложности задачи, на подвыборках из 1 000 размеченных примеров авторы FixMatch получили 80,14% accuracy для supervised CTA и 94,83% для FixMatch CTA. У них другая архитектура и другой бюджет обучения, поэтому эффект псевдометок в этом ДЗ оценивается внутри каждой пары запусков. [Sohn et al., 2020, приложение, таблица 10](https://proceedings.neurips.cc/paper/2020/file/06964dce9addb1c5cb5d6e3d9838f733-Supplemental.pdf)

## Обучение

Классификатор каждой сети выдаёт десять логитов. Вход сохраняет исходный размер и нормализуется по статистикам ImageNet. Оптимизатор AdamW минимизирует кросс-энтропию с `weight_decay=0.0001`. В каждой эпохе 63 шага по 64 изображения. В конце эпохи последние 32 места дополняются случайными примерами, поэтому даже последний батч имеет одинаковый размер в обеих сериях.

| Эпохи | Обучаемая часть сети | Случайные преобразования тренировочного изображения |
| --- | --- | --- |
| 1–3 | Классификатор | Горизонтальное отражение с вероятностью 0,5 |
| 4–6 | Классификатор и последние блоки | Отражение, кадр площадью 85–100% исходного, цветовой джиттер 0,08 |
| 7–9 | Дополнительно средние блоки | Отражение, кадр площадью 75–100%, джиттер 0,15 |
| 10–12 | Вся сеть | Отражение, кадр площадью 65–100%, джиттер 0,22 |

Джиттер независимо меняет яркость, контраст и насыщенность. Кадр масштабируется обратно до 96 × 96. Для валидации и итогового теста используется исходное изображение.

Стартовые скорости обучения от входа к выходу равны `3e-5`, `8e-5`, `2e-4` и `1e-3`. В ResNet-18 последние и средние блоки соответствуют `layer4` и `layer3`. В MobileNetV3-Small это `features[9:]` и `features[4:9]`. После каждой эпохи `ReduceLROnPlateau` вдвое уменьшает скорости, если валидационная кросс-энтропия не улучшила предыдущее лучшее значение хотя бы на 1%.

Режим BatchNorm выбран на контрольных сериях до оценки на тесте. Сравнивалась лучшая точность на валидации за эпохи 7–12. При обновлении скользящих средних и дисперсий в размороженных блоках получились 90,4% у ResNet-18 и 81,4% у MobileNetV3-Small. С фиксированными статистиками — **91,2% и 84,1%** соответственно. Поэтому в основных сериях используются статистики предобучения, а параметры масштаба и сдвига обучаются в размороженных блоках. Контроль с обновлением статистик воспроизводится командой `python train.py --bn-stats adaptive --through supervised --run runs/bn-adaptive`.

### Отбор псевдометок и контрольное сравнение

1. Сохраняем модель после шестой эпохи вместе с состоянием оптимизатора и расписанием скоростей обучения. У каждой архитектуры свой учитель.
2. Прогоняем через учителя оригинал и горизонтальное отражение каждого неразмеченного изображения. Сохраняем предсказание, если обе версии дают один класс и обе вероятности этого класса не ниже 0,90.
3. Для ранжирования используем меньшую из двух вероятностей. В каждом предсказанном классе оставляем до 300 самых уверенных примеров. Такой лимит ограничивает долю массовых классов. В неразмеченном наборе есть и посторонние категории, например поезда. Точность правила отбора отдельно оцениваем на размеченной валидации.
4. Из сохранённого состояния запускаем два варианта на шесть эпох. В контрольном батче 64 изображения с исходной разметкой. Во втором варианте первые 48 изображений те же, а оставшиеся 16 получают псевдометки. В обеих сериях по **756 шагов** с учётом первых шести эпох. У обеих серий одинаковы объём батча, расписание аугментаций и правила подбора модели.
5. Для каждого варианта выбираем эпоху дообучения с наибольшей validation accuracy. При равенстве используем меньшую validation loss. Сохранённые модели оцениваем на одном и том же тесте. **Accuracy** — доля верных ответов. **Macro-F1** — среднее F1 по десяти классам с одинаковым весом каждого класса.

## Воспроизведение

Команды рассчитаны на macOS или Linux, Python 3.11–3.14. Из корня репозитория надо выполнить:

```bash
git switch hw1_stl10_semisupervised
cd hw1
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest -v test_protocol
python data.py
python train.py
python report.py --from-run runs/full --output runs/full/report
```

`data.py` скачивает официальный архив размером 2,46 ГиБ и проверяет контрольные суммы. При первом запуске `train.py` скачивает стартовые веса Torchvision. Обучение автоматически выбирает CUDA, Metal на Mac или CPU. Готовые этапы сохраняются в `runs/full` и переиспользуются при повторном запуске. Для независимого эксперимента укажите новый каталог через `--run`.

Короткий запуск после загрузки данных проверяет весь цикл одной сети на 800 размеченных примерах и 1 000 кандидатах для псевдометок. Он использует по одной эпохе на этап и порог 0,70. Его результаты сохраняются в `runs/quick`.

```bash
python train.py --quick --model mobilenet_v3_small
```

Команда `python report.py` перестраивает обе иллюстрации из опубликованного JSON. При повторении обучения журнал содержит поэпоховые метрики и скорости обучения, лучшие веса лежат в `runs/full/<архитектура>/<вариант>/weights.pt`, а индексы, классы и уверенности принятых псевдометок — в `pseudo/pseudo_labels.npz`.
